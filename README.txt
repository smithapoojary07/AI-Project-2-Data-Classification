ARTIFICIAL INTELLIGENCE - PROJECT 2
DATA CLASSIFICATION USING AI

Contents:
1. data_classification_project2.py - Complete Python program
2. README.txt - Instructions

Requirements:
- Python 3
- pandas
- matplotlib
- scikit-learn

Install the required libraries:
    python -m pip install pandas matplotlib scikit-learn

Run the project:
    python data_classification_project2.py

The program:
- Loads the Iris dataset
- Displays and understands the dataset
- Splits data into training and testing sets
- Applies a Decision Tree classification algorithm
- Trains and tests the model
- Calculates accuracy
- Displays a classification report
- Visualizes classification results
- Predicts the class of new data
